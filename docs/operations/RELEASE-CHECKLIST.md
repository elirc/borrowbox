# Release checklist

- [ ] Scope is represented by the sprint milestone and closed issues.
- [ ] Pull request review explains risks and trade-offs.
- [ ] Locked restore, format, Release build, all tests, and vulnerability audit pass in CI.
- [ ] OpenAPI and integration guidance match endpoints.
- [ ] Security warnings and persistence mode are accurate.
- [ ] Runbook and rollback/recovery assumptions were reviewed.
- [ ] Changelog describes user-visible changes and known limits.
- [ ] Version tag points to the green commit on `main`.
- [ ] GitHub release links the tag and notes.
